# WebDAV 同步

> 把电脑上的文件夹与网盘保持一致的 ZTools 插件

让电脑上的文件夹与任意支持 WebDAV 的网盘（坚果云、Nextcloud、群晖 NAS 等）自动保持一致。文件改了自动同步到其他设备，支持双向同步 / 只上传 / 只下载，内置冲突处理、删除保护与同步记录。

## ✨ 功能特性

- **多文件夹同步**：同时管理多个「电脑文件夹 ↔ 云端文件夹」，逐个显示状态与最近同步时间
- **三种同步方式**：双向同步、只上传（备份到云端）、只下载，添加文件夹时按需选择
- **自动同步**：文件一有变化就同步，另有定时检查与启动时检查兜底；每个文件夹可单独调整
- **全局暂停**：整理文件、连热点、演示前一键暂停（30 分钟 / 1 小时 / 4 小时 / 一直），到期自动恢复并补上暂停期间的变更
- **冲突处理**：两边同时改了同一个文件时弹窗对比修改时间和大小，保留任一侧或两个都留，绝不默默覆盖
- **同步记录**：每次同步都有记录，展开可回看当次每个文件的上传 / 下载 / 删除明细与错误
- **实时进度**：文件数 + 字节量进度条，底部栏实时显示上传 / 下载速率
- **删除与覆盖保护**：本地删除与被覆盖的旧版文件都进系统回收站，可随时找回；一次要删很多文件时先停下来请你确认
- **云端丢失保护**：云端同步文件夹被删 / 挪走时立即暂停，弹窗让你二选一，绝不自作主张删本地
- **改名秒同步**：文件改名只同步名字不重传，几个 GB 的视频改个名瞬间完成
- **多账号多服务器**：可添加多台 WebDAV 服务器（如坚果云 + 家用 NAS），每个文件夹各自指定
- **带宽限速**：按服务器分别限制上传 / 下载速度，白天同步不拖累其他上网
- **HTTP 代理**：公司内网等无法直连云端的场景可配置代理（支持账号密码）
- **自签名证书**：群晖 / QNAP 等 NAS 的一键信任开关与 CA 证书导入
- **跨平台文件名安全**：自动处理 macOS / Windows / Linux 的文件名差异；`.DS_Store`、`Thumbs.db` 等系统垃圾默认排除，支持自定义排除规则
- **实验：ZTools 插件同步**：把 ZTools 的插件目录也同步到云端，多台设备的插件列表自动保持一致

前提：电脑上已安装 [ZTools](https://github.com/ztool-center/ztools)，并且有一个支持 WebDAV 功能的网盘账号。

### 第一步：连接网盘

点击「配置 WebDAV」，填入服务器地址、用户名、密码，点「测试连接」：

| 网盘 | WebDAV 地址 | 说明 |
| --- | --- | --- |

| Nextcloud | `https://你的域名/remote.php/dav/files/你的用户名/` | — |
| 群晖 NAS | `http://NAS地址:5005/` 或 `https://NAS地址:5006/` | 套件中心安装「WebDAV Server」套件并启用（默认 HTTP 5005 / HTTPS 5006） |

## 📖 使用说明

### 三种同步方式怎么选

| 方式 | 方向 | 适合场景 |
| --- | --- | --- |
| 双向同步（默认） | 电脑 ⇄ 云端 | 多台设备之间保持一致 |
| 只上传 | 电脑 → 云端 | 电脑是原件，云端只做备份 |
| 只下载 | 云端 → 电脑 | 云端是主副本，电脑只要一份 |

### 自动同步与暂停

- 默认行为：文件变化即同步 + 定时检查兜底；都可在设置中关闭
- 单个文件夹可以在「同步设置 → 高级设置」里单独关掉自动同步（只手动同步）、自定义检查频率
- 顶栏暂停按钮可一键暂停自动同步（30 分钟 / 1 小时 / 4 小时 / 一直）；到期自动恢复，并自动补上暂停期间积累的变更
- 暂停期间手动「立即同步」不受影响

### 有冲突了怎么办

两台设备在两次同步之间都改了同一个文件，就会产生冲突。插件会弹窗对比两边的修改时间和文件大小：

<div>
  <img src="https://raw.githubusercontent.com/Particaly/ztools-webdav-sync/main/docs/screenshots/conflict.png" alt="冲突处理" width="550" />
</div>

- 可以选择「保留电脑版本」「保留云端版本」或「两个都留」（云端版本会另存为 `文件名.conflict.扩展名` 副本，两边内容都不丢）
- 勾选「其余的冲突都这样处理」可以批量处理本轮剩余冲突
- 后台自动同步遇到的冲突不会打断你，会集中到「待处理」面板（顶栏时钟图标），有空时逐条或批量决定即可
- 拿不准时选「两个都留」最保险

### 查看同步记录

顶栏「同步记录」可以回看每一轮同步：何时开始结束、为什么触发（手动 / 定时 / 文件变化 / 启动 / 失败重试）、改了哪些文件、有没有错误。展开任意一行可看逐文件明细；你对删除确认、冲突等的每次处理也都在这个时间线里：

### 多个网盘账号

设置页可以添加多台 WebDAV 服务器（比如坚果云 + 家用 NAS 各一台）。每台服务器的地址、账号、限速、代理、证书设置各自独立，添加同步文件夹时选定用哪台即可。单服务器用户感觉不到这项功能的存在。

### 网速与网络环境

- **带宽限速**：设置页按服务器分别填写上传 / 下载上限（KB/s），留空不限速；限的是这台服务器的传输总量，多个文件夹共享额度
- **请求频率**：对接入有频率配额的服务器（如坚果云）会自动采用保守限速，也可以手动设置每秒请求上限
- **HTTP 代理**：公司内网等无法直连的场景，可在设置页为服务器配置代理（支持代理账号密码）；https 连接经代理隧道端到端加密，代理看不到内容
- **自签名证书**：群晖 / QNAP 等 NAS 常用自签名证书，默认严格校验会连接失败。设置页提供「信任此服务器证书」开关（仅建议用于自己可控的 NAS / 内网设备）与更安全的「CA 证书」导入
- **明文警告**：使用 `http://` 地址时界面会常驻警告（密码与文件内容可能被窃听），建议尽量使用 `https://`

### 实验：ZTools 插件同步

设置 → 实验里开启后，同步列表会出现一条「ZTools 插件」，把本机 ZTools 的插件目录双向同步到云端：

- 不同操作系统的插件自动分目录存放，Mac 和 Windows 的设备不会互相同步到不兼容的版本
- 多台设备在设置里选同一个云端文件夹即可互通
- 另一台设备同步来的插件会自动登记进 ZTools 已安装列表，无需重启
- 该记录默认不自动同步（跟随排程），支持立即同步与暂停；关闭开关即退出同步，不会删除任何一端的插件文件

## 🛡️ 数据安全设计

同步类工具最怕「不小心把文件删了」。这个插件为此做了层层保护：

- **大量删除先确认**：一轮同步要删除的文件突然变多时（超过阈值），整批挂起并按目录结构展示，请逐个、按目录或整批确认，确认前一个文件都不动
- **删除进回收站**：本机文件的删除一律进系统回收站（macOS 废纸篓 / Windows 回收站），不直接抹掉
- **覆盖有保险**：云端更新覆盖本地旧版之前，旧版本先自动移入回收站 —— 另一台设备误改、勒索加密、文档损坏时都能找回
- **绝不无备份覆盖**：回收站不可用时，宁可放弃本次操作并明确报错
- **云端丢失你来定**：云端同步文件夹被删 / 挪走时立即暂停（零删除零传输），弹窗让你选择「重新上传到云端」还是「删除电脑上的文件」；决定前云端恢复了则自动撤销
- **崩溃安全**：断电、断网、强退后的下一轮自动识别并修复意外中断的传输，不会把半截文件冒充完整文件
- **密码不明文保存**：密码加密后落盘，界面上也不明文展示

## ⚠️ 使用须知

- **ZTools 退出后同步即停止**：插件不会脱离 ZTools 在后台常驻。期间其他设备的变更，会在下次打开 ZTools 后的首轮同步自动补齐
- **符号链接不同步**：同步目录里的软链接会被跳过（保守取向，避免越出同步目录的意外读写）
- **改名检测是启发式**：改名的同文件若内容也变了、或无法确认是同一个文件，会回落为「删旧名 + 传新名」，结果一致但会多传一次
- **深度校验是可选的兜底**：开启后会定期重算全部文件哈希来发现更隐蔽的改动，大目录会明显变慢，重要数据再开

## ❓ 常见问题

**Q：换新电脑怎么迁移文件？**
新电脑装好插件 → 连接同一个网盘 → 添加同步文件夹（本地选一个空文件夹，方式选「只下载」或「双向同步」），首轮同步会把云端文件完整下载到新电脑。

**Q：为什么打开插件没有立即开始同步？**
打开插件不会立刻同步，首轮跟随每个文件夹各自的自动同步时间点。急着同步就点底部「立即同步」。

**Q：同步会把我还没改完的文件传上去吗？**
文件变化监听有去抖窗口，连续保存只会在停笔后触发一轮；定时检查也只传有变化的部分。没传完就断开也没关系，下一轮会接着传。

**Q：两台电脑上的插件会互相打架吗？**
不会。同一文件夹的多设备并发由互斥锁保护，同一时刻只有一台在执行，传输不会重复、记录不会写坏；「多设备互斥同步」设置项默认开启。

**Q：支持 Linux 吗？**
插件本身跨平台（macOS / Windows / Linux），文件名的跨平台差异（NFC 规范化、大小写冲突、Windows 非法字符等）都会自动处理；大小写冲突会明确报错提示改名，不会静默覆盖。
