## 功能特性

- **多文件夹同步**：同时管理多个「电脑文件夹 ↔ 云端文件夹」，逐个显示状态与最近同步时间
- **三种同步方式**：双向同步、只上传（备份到云端）、只下载，添加文件夹时按需选择
- **自动同步**：文件变化即同步，另有定时检查与启动时检查兜底；每个文件夹可单独调整
- **全局暂停**：整理文件、连接受限网络（如手机热点）、演示前可一键暂停（30 分钟 / 1 小时 / 4 小时 / 一直），到期自动恢复并补上暂停期间的变更
- **冲突处理**：两台设备同时修改同一文件时弹窗对比修改时间和大小，可保留任一侧或同时保留，不会静默覆盖
- **同步记录**：每次同步都有记录，展开可回看当次每个文件的上传 / 下载 / 删除明细与错误
- **实时进度**：文件数 + 字节量进度条，底部栏实时显示上传 / 下载速率
- **删除与覆盖保护**：本地删除与被覆盖的旧版文件均进入系统回收站，可随时找回；单轮删除数量超过阈值时暂停并请求确认
- **云端丢失保护**：云端同步文件夹被删除 / 移动时立即暂停，弹窗供选择处理方式，不会自行删除本地文件
- **改名增量同步**：文件重命名只同步名称不重传内容，大文件改名也能即时完成
- **多账号多服务器**：可添加多台 WebDAV 服务器（如坚果云 + 家用 NAS），每个文件夹各自指定
- **带宽限速**：按服务器分别限制上传 / 下载速度，同步不影响正常上网
- **HTTP 代理**：公司内网等无法直连云端的场景可配置代理（支持账号密码）
- **自签名证书**：群晖 / QNAP 等 NAS 的一键信任开关与 CA 证书导入
- **跨平台文件名安全**：自动处理 macOS / Windows / Linux 的文件名差异；`.DS_Store`、`Thumbs.db` 等系统垃圾默认排除，支持自定义排除规则
- **实验：ZTools 插件同步**：把 ZTools 的插件目录也同步到云端，多台设备的插件列表自动保持一致

## 使用说明

### 三种同步方式的适用场景

| 方式 | 方向 | 适合场景 |
| --- | --- | --- |
| 双向同步（默认） | 电脑 ⇄ 云端 | 多台设备之间保持一致 |
| 只上传 | 电脑 → 云端 | 电脑是原件，云端只做备份 |
| 只下载 | 云端 → 电脑 | 云端是主副本，电脑只要一份 |

### 自动同步与暂停

- 默认行为：文件变化即同步 + 定时检查兜底；都可在设置中关闭
- 「监听文件变化」独立开关（设置 → 同步）：关闭后本地改动不再即时触发，只按检查频率定时对账
- 单个文件夹可以在「同步设置 → 高级设置」里单独关掉自动同步（只手动同步）、关掉监听文件变化、自定义检查频率
- 顶栏暂停按钮可一键暂停自动同步（30 分钟 / 1 小时 / 4 小时 / 一直）；到期自动恢复，并补上暂停期间积累的变更
- 暂停期间手动「立即同步」不受影响

### 有冲突了怎么办

两台设备在两次同步之间修改了同一文件，就会产生冲突。插件会弹窗对比两侧的修改时间和文件大小：

<div>
  <img src="https://raw.githubusercontent.com/Particaly/ztools-webdav-sync/main/docs/screenshots/conflict.png" alt="冲突处理" width="550" />
</div>

- 可以选择「保留电脑版本」「保留云端版本」或「同时保留」（云端版本会另存为 `文件名.conflict.扩展名` 副本，两侧内容都不丢）
- 勾选「对其余冲突应用相同处理」可批量处理本轮剩余冲突
- 后台自动同步遇到的冲突不会打断操作，会集中到「待处理」面板（顶栏时钟图标），可稍后逐条或批量处理
- 不确定时建议选择「同时保留」

### 多个网盘账号

设置页可以添加多台 WebDAV 服务器（如坚果云 + 家用 NAS 各一台）。每台服务器的地址、账号、限速、代理、证书设置各自独立，添加同步文件夹时选定所用服务器即可。单服务器用户不受影响。

### 网速与网络环境

- **带宽限速**：设置页按服务器分别填写上传 / 下载上限（KB/s），留空不限速；限制的是该服务器的传输总量，多个文件夹共享额度
- **请求频率**：对有频率配额限制的服务器（如坚果云）自动采用保守限速，也可手动设置每秒请求上限
- **HTTP 代理**：公司内网等无法直连的场景，可在设置页为服务器配置代理（支持代理账号密码）；https 连接经代理隧道端到端加密，代理无法获知内容
- **自签名证书**：群晖 / QNAP 等 NAS 常用自签名证书，默认严格校验会连接失败。设置页提供「信任此服务器证书」开关（仅建议用于自己可控的 NAS / 内网设备）与更安全的「CA 证书」导入
- **明文警告**：使用 `http://` 地址时界面会常驻警告（密码与文件内容可能被窃听），建议尽量使用 `https://`

### 实验：ZTools 插件同步

在「设置 → 实验」中开启后，同步列表会出现一条「ZTools 插件」，将本机 ZTools 的插件目录双向同步到云端：

- 不同操作系统的插件自动分目录存放，Mac 与 Windows 设备不会互相同步不兼容的版本
- 多台设备在设置里选同一个云端文件夹即可互通
- 插件运行时生成的数据库文件（`*.db`、`*.db-wal`、`*.db-shm`，如 Everything 的搜索索引）默认不同步 —— 这类文件由各电脑各自维护，同步没有意义
- 只同步已安装列表里的插件：插件目录中累积的旧版本 asar 与未安装的文件不再参与上传 / 下载（不删除本机与云端的任何文件，云端历史遗留从此不再增长）。已安装列表经宿主高级权限与注册表投影读取，需在宿主「设置 → 高级权限」中批准本插件的申请；**未批准期间该记录暂停同步**（不做任何上传 / 下载，权限申请自动提交，批准后自动开始）
- **运行中的插件不会同步出错**：同步前检测正在运行的插件（Windows 上运行中的插件文件被占用，覆盖 / 删除必然失败），需要更新它们时弹窗展示将被重新安装的插件（图标 + 名称）—— 确认后先卸载旧版本（保留插件数据），随即自动同步云端版本并重新登记安装；「暂不处理」则本轮跳过这些文件，其余照常。后台自动同步不弹窗、静默跳过，手动同步时才询问
- 本插件（WebDAV 同步）自身的文件不参与同步 —— 同步引擎就运行在它里面，无法被停止也无法被替换；自身的升级请走 ZTools 的插件安装 / 升级流程
- 本地与云端目录、同步方式由插件自动发现不可修改；检查频率、冲突处理、排除规则、使用服务器等在同步列表「ZTools 插件」记录的菜单 →「同步设置」中调整
- 其他设备同步来的插件自动登记进 ZTools 已安装列表，无需重启
- 该记录跟随排程同步，支持立即同步与暂停；关闭开关即退出同步，不删除任何一端的插件文件

## 数据安全设计

同步类工具需要重点防范误删文件。本插件为此设计了多层保护：

- **大量删除先确认**：单轮待删除数量突然增多（超过阈值）时，整批挂起并按目录结构展示，可逐个、按目录或整批确认，确认前不删除任何文件
- **删除进回收站**：本机文件的删除一律进入系统回收站（macOS 废纸篓 / Windows 回收站），不直接删除
- **覆盖有保险**：云端更新覆盖本地旧版之前，旧版本先自动移入回收站 —— 其他设备误改、勒索加密、文档损坏时均可找回
- **无备份不覆盖**：回收站不可用时，放弃本次操作并明确报错
- **云端丢失由用户决定**：云端同步文件夹被删除 / 移动时立即暂停（零删除零传输），弹窗供选择「重新上传到云端」或「删除电脑上的文件」；决定前云端恢复则自动撤销
- **崩溃安全**：断电、断网、强制退出后的下一轮自动识别并修复意外中断的传输，不会将未完成的文件当作完整文件
- **密码不明文保存**：密码加密后落盘，界面上不明文展示

## 使用须知

- **ZTools 退出后同步即停止**：插件不会脱离 ZTools 在后台常驻。期间其他设备的变更，会在下次打开 ZTools 后的首轮同步自动补齐
- **符号链接不同步**：同步目录中的软链接会被跳过（保守策略，避免越出同步目录的意外读写）
- **改名检测是启发式**：改名的文件若内容同时变化、或无法确认是同一文件，会退回「删除旧名 + 上传新名」处理，结果一致但会多传输一次
- **深度校验是可选的兜底**：开启后定期重算全部文件哈希以发现更隐蔽的改动，大目录下会明显变慢，建议仅对重要数据开启

## 常见问题

**Q：换新电脑怎么迁移文件？**
新电脑安装插件 → 连接同一网盘 → 添加同步文件夹（本地选择一个空文件夹，方式选择「只下载」或「双向同步」），首轮同步会把云端文件完整下载到新电脑。

**Q：为什么打开插件没有立即开始同步？**
打开插件不会立刻同步，首轮跟随各文件夹的自动同步时间点。如需立即同步，可点击底部「立即同步」。

**Q：同步会把我还没改完的文件传上去吗？**
文件变化监听有去抖窗口，连续保存只会在编辑停止后触发一轮；定时检查也只传输有变化的部分。传输中断后无需处理，下一轮会继续传输。

**Q：两台电脑上的插件会互相打架吗？**
不会。同一文件夹的多设备并发由互斥锁保护，同一时刻只有一台设备在执行，传输不会重复、记录不会损坏；「多设备互斥同步」设置项默认开启。

**Q：支持 Linux 吗？**
插件本身跨平台（macOS / Windows / Linux），文件名的跨平台差异（NFC 规范化、大小写冲突、Windows 非法字符等）均自动处理；大小写冲突会明确报错提示重命名，不会静默覆盖。
